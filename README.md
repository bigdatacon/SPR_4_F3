🧾 Датасет

Использован стандартный набор аугментаций и нормализаций, аналогичный рассмотренному на уроке

Отдельно заранее вычислена калорийность блюд, состоящих из одного ингредиента, чтобы:

✅ если блюдо состоит из 1 ингредиента — калорийность предсказывалась точно

⚠️ если блюдо состоит из нескольких известных ингредиентов — калорийность считается так,
как будто пропорции ингредиентов равны, что не является оптимальным

по логике модель должна сама выделять пропорции и обучаться им

такая модель реализована и лежит в папке MODEL_1_WORK

однако на 10 эпохах она показала результат около MAE ≈ 51 kcal на блюдо

вероятно, при большем числе эпох результат был бы лучше,
но из-за ограничений по времени и вычислительным ресурсам
в качестве основной была выбрана текущая, более стабильная модель

Для ингредиентов, калорийность которых неизвестна:

используется средняя калорийность по группе продуктов

значения взяты из открытых источников (интернет)

логика реализована в файле dataset.py, функция avg_ingr_cal

🎯 Таргет и метрики

В качестве таргета используется:

калорийность на 100 г продукта

Модель обучается предсказывать kcal / 100 г

Для оценки качества на уровне блюда:

kcal_per_100g × масса блюда

Таким образом:

MAE на 100 г — отражает точность оценки плотности калорий

MAE на блюдо — отражает реальную ошибку для пользователя

🧠 Модель

📦 дополнительные признаки

В зависимости от конфигурации применяются разные способы fusion:

Concat — конкатенация эмбеддингов

Hadamard product — поэлементное умножение эмбеддингов

Cross-modal attention — кросс-модальное внимание

📌 Общий вывод

При наличии:

локальных вычислительных ресурсов (CUDA)

большего времени на обучение

оптимально использовать «справочную модель» из папки MODEL_1_WORK,
поскольку она:

самостоятельно обучается пропорциям ингредиентов

использует точную калорийность для блюд из одного ингредиента

Однако:

данной модели требуется большее число эпох

необходимо тестирование с разными аугментациями

локально это оказалось невозможным:

kernel периодически падал без информативного лога

ошибка не воспроизводилась в debug-режиме

многие правки вносились вручную, с проверками на малой выборке

Несмотря на это:

основная приложенная модель

протестированная в SPR_4_FIN.ipynb

на полной выборке показала MAE на блюдо < 50 kcal,
что можно считать хорошим и устойчивым результатом
