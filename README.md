Датасет
Используется стандартный набор аугментаций и нормализаций, аналогичный рассмотренному на уроке

Отдельно заранее вычислена калорийность блюд, состоящих из одного ингредиента, чтобы:

если блюдо состоит из 1 ингредиента — калорийность предсказывалась точно

если блюдо состоит из нескольких известных ингредиентов — калорийность считается так,
как будто пропорции ингредиентов равны, что не является оптимальным

по логике модель должна сама выделять пропорции и обучаться им

такая модель реализована и находится в папке MODEL_1_WORK

на 10 эпохах она показала результат около MAE ≈ 51 kcal на блюдо

вероятно, при большем количестве эпох результат был бы лучше,
однако из-за ограничений по времени и вычислительным ресурсам
в качестве основной выбрана текущая, более стабильная модель

Для ингредиентов, калорийность которых неизвестна:

используется средняя калорийность по группе продуктов

значения взяты из открытых источников (интернет)

логика реализована в файле dataset.py в функции avg_ingr_cal

Таргет и метрики

В качестве таргета используется:

калорийность на 100 г продукта

Модель обучается предсказывать kcal / 100 г

Для оценки качества на уровне блюда:

калорийность на 100 г × масса блюда

Таким образом используются две метрики:

MAE на 100 г — отражает точность оценки калорийной плотности

MAE на блюдо — отражает реальную пользовательскую ошибку
